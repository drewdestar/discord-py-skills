# Code of Conduct

Be kind. This pack is built by one person in their spare time, and
the people who open issues and pull requests are doing it for free too.

- Be respectful in issues, pull requests, and discussions, even when
  you disagree. Disagree with the idea, not the person.
- No harassment, hate speech, or personal attacks, in any form.
- No spam, no self-promotion, no AI-generated bulk contributions.
  A pull request must be a change you understand and can explain.
- If a maintainer asks you to change something, that is not a
  rejection. Small, tested, honest changes land fastest.

If someone's behaviour in this repo makes the project worse to be
in, open an issue or contact the maintainer through GitHub. The
maintainer may warn, block, or remove contributions that break
these rules. The goal is a project people want to come back to.
